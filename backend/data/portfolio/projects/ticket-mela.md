# Ticket Mela

- **Type:** Blockchain & Decentralized Ticketing Platform
- **Completion Date:** Jul 2024
- **GitHub URL:** https://github.com/MachaVivek/TicketMela
- **Technologies:** Solidity, Ethereum, Smart Contracts, OpenZeppelin, REST APIs, Blockchain, Web3

## Overview & Highlights
Ticket Mela is a decentralized ticketing infrastructure built on Ethereum using Solidity smart contracts to eliminate ticket scalping and counterfeit tickets while ensuring secure asset ownership and transfer.

## Key Features & Engineering Details
- Engineered blockchain-based ticketing infrastructure using Solidity smart contracts, enabling decentralized ownership and secure asset transfers.
- Built Ethereum-integrated backend services and REST APIs to automate ticket issuance, validation, and transaction processing.
- Implemented secure contract architecture using OpenZeppelin standards and developed on-chain business logic for seat allocation and dynamic pricing.
