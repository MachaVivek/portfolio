# AI Tour Guide (RAG Chatbot)

- **Type:** Full-Stack AI / Retrieval-Augmented Generation (RAG) Application
- **Completion Date:** Oct 2025
- **GitHub URL:** https://github.com/MachaVivek/AiTourGuide
- **Technologies:** Python, FastAPI, React, LangChain, OpenAI API, Pinecone, RAG, Supabase, Tailwind CSS, shadcn/ui, Vercel

## Overview & Highlights
AI Tour Guide is an end-to-end intelligent travel companion application using Retrieval-Augmented Generation (RAG) to deliver personalized, context-rich travel recommendations and destination insights in real time.

## Key Features & Engineering Details
- Architected and developed a full-stack Retrieval-Augmented Generation (RAG) application to provide context-aware travel recommendations using Large Language Models.
- Implemented vector-based semantic search using Pinecone, enabling efficient retrieval of relevant travel knowledge and improving response accuracy for user queries.
- Integrated LangChain and OpenAI APIs to build an end-to-end retrieval and generation pipeline supporting intelligent question answering and contextual reasoning.
- Designed and developed scalable FastAPI backend services for query processing, prompt orchestration, response generation, and API management.
- Built a responsive React-based frontend with Tailwind CSS and shadcn/ui, delivering an intuitive conversational experience across desktop and mobile devices.
- Implemented chat session management, user profile storage, and conversation persistence using Supabase to support personalized interactions and session continuity.
- Applied prompt engineering, context retrieval, and knowledge augmentation techniques to improve relevance, consistency, and quality of AI-generated responses.
- Deployed and maintained the application on Vercel with a modular architecture, enabling scalability, maintainability, and rapid feature iteration.
