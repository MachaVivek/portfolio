# Daily Hub

- **Type:** Full-Stack Web Application
- **Completion Date:** Mar 2024
- **GitHub URL:** https://github.com/MachaVivek/DailyHub_Backend
- **Technologies:** React, Node.js, Express.js, MongoDB, REST APIs, JWT, OTP Authentication, WebSockets, Socket.IO, Nodemailer, Chart.js, Git

## Overview & Highlights
Daily Hub is a comprehensive productivity and social collaboration platform integrating real-time chat, encrypted diary management, expense tracking, and content publishing into a single responsive web interface.

## Key Features & Engineering Details
- Engineered a full-stack web application integrating productivity and social collaboration features including real-time chat, encrypted diary management, expense tracking, and content publishing.
- Developed scalable REST APIs using Node.js and Express.js to support user management, content operations, and secure data access workflows.
- Implemented JWT-based authentication, Firebase OTP verification, and data encryption mechanisms to ensure secure user access and privacy protection.
- Integrated WebSockets and Socket.IO to enable low-latency real-time messaging, notifications, and live synchronization across connected clients.
- Designed reusable React components and responsive user interfaces, improving maintainability, performance, and cross-device compatibility.
- Implemented data visualization charts, speech-to-text, text-to-speech, pagination, and notification systems to enhance user engagement and application usability.
