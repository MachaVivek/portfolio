# Notes App with Observability Stack

- **Type:** Full-Stack Web Application with Production Monitoring & DevOps
- **Completion Date:** Dec 2025
- **GitHub URL:** https://github.com/MachaVivek/Observability
- **Technologies:** Node.js, Express.js, PostgreSQL, Docker, Docker Compose, Prometheus, Grafana, Loki, Promtail, Alertmanager, Winston, DevOps, Observability

## Overview & Highlights
Notes App with Observability Stack is a production-grade containerized application demonstrating modern DevOps and SRE practices by monitoring full-stack performance, query latencies, structured logs, and alert triggers in real time.

## Key Features & Engineering Details
- Engineered a full-stack Notes Management application using Node.js, Express.js, and PostgreSQL with complete CRUD functionality and persistent data storage.
- Designed and deployed a production-grade observability stack using Prometheus, Grafana, Loki, Promtail, and Alertmanager for monitoring, logging, visualization, and alerting.
- Implemented custom Prometheus metrics for HTTP requests, response latency, error rates, and database query performance to enable real-time system monitoring.
- Built structured logging pipelines using Winston and centralized log aggregation through Loki and Promtail, improving debugging and operational visibility.
- Configured automated alerting workflows with Prometheus and Alertmanager to detect high-traffic conditions, application failures, and performance bottlenecks.
- Containerized the entire application and monitoring infrastructure using Docker and Docker Compose, ensuring consistent deployment and environment reproducibility.
- Developed health monitoring, metrics collection, and load-testing workflows to validate system reliability, scalability, and performance under traffic spikes.
- Applied DevOps, Observability, Monitoring, and Performance Engineering practices to improve system resilience, maintainability, and operational efficiency.
